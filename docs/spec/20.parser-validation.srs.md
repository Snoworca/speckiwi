## 1. Scope Overview

이 문서는 SRS Markdown 문서 탐색, Requirement Block 파싱, normalized requirement record 생성, validation rule 적용을 정의한다.

## 2. Scope Boundaries

### In Scope

- SRS 파일 탐색
- Requirement heading 파싱
- metadata table 파싱
- Acceptance Criteria 파싱
- Verification Evidence 및 Trace Links 파싱
- validation diagnostics 생성

### Out of Scope

- Markdown 전체 렌더링
- 일반 문서 요약
- 외부 URL 네트워크 검증
- YAML 또는 다른 요구사항 포맷 파싱

## 3. Assumptions and Constraints

- SRS 문서는 SRS-MD Authoring Rules v1.0.0을 따른다.
- 파서는 가능한 한 부분 파싱을 제공한다.
- 기본 명령은 네트워크 호출을 하지 않는다.
