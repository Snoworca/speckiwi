## 1. Scope Overview

이 문서는 `speckiwi` Node.js CLI의 명령, 옵션, 출력, mutation behavior, exit code 정책을 정의한다.

## 2. Scope Boundaries

### In Scope

- CLI entrypoint
- init, validate, extract, list, show, targets, scopes
- status, AC, evidence, trace mutation 명령
- summary, links check, mcp launcher
- exit code와 output format

### Out of Scope

- 웹 UI
- 대화형 TUI
- 원격 서버 API
- YAML export/import

## 3. Assumptions and Constraints

- CLI는 Node.js package bin으로 제공된다.
- CLI는 core service를 호출한다.
- 쓰기 명령은 최소 변경 원칙을 따른다.

- [x] AC-5: `speckiwi init`은 대문자 `AGENTS.md`를 항상 생성 또는 갱신한다.
- [x] AC-6: `speckiwi init`은 대문자 `CLAUDE.md`를 항상 생성 또는 갱신한다.
- [x] AC-7: agent 파일에 추가되는 managed block은 `# SpecKiwi SRS 워크플로 v1.1` heading, `<!-- /SpecKiwi SRS 워크플로 -->` suffix marker, SRS source-of-truth 강제 문장, current work status workflow를 포함한다.
- [x] AC-8: 동일한 현재 버전 managed block이 이미 있으면 중복 삽입하지 않고, 다른 버전 또는 legacy unversioned block이 있으면 현재 버전 block으로 교체한다.
- [x] AC-9: 기존 파일이 있으면 기본적으로 덮어쓰지 않는다.
- [x] AC-10: `init --target`은 Target Map row를 `planned`로 만들 수 있지만 `Active Target` metadata value는 비워 둔다.
- [x] AC-11: init으로 생성된 index는 빈 Completed Work Log table을 포함한다.

#### Requirement

### IR-CLI-080 — doctor reports drift in the skills an agent actually loads

| Field | Value |
| --- | --- |
| Type | interface |
| Target | v2.5.1 |
| Status | implemented |
| Priority | critical |
| Tags | doctor, skills, drift |
| Risk | high |
| Stability | evolving |
| Verification Method | test |
| GitHub Issue | - |
| Related Docs | - |

#### Requirement

`speckiwi doctor` SHALL report drift between the bundled skills and the installed copies an agent actually loads, covering each present agent's global skills directory and the project-local agent skill directories, and SHALL name the drifted skills together with the command that reinstalls them. A shared contract file under `_shared/kiwi` SHALL be compared as well, because a stale contract silently changes the behaviour of every skill that cites it. A directory that is not provisioned SHALL report `ok` rather than drift, so a project that never installed skills is not reported as broken. Line endings SHALL NOT count as drift. The project mirror's exclusion manifest SHALL apply only to that mirror and SHALL NOT suppress a globally installed skill.

#### Rationale

An agent's behaviour comes from the installed skill, not from the bundled one, and nothing reported when the two diverged. Measured in this repository on 2026-07-30: `doctor` reported every check `ok` while the globally installed `kiwi-wave-master` was 169 lines against a bundled 573 — missing the entire run-root preflight gate and the critical-gates table that v2.4.2 and v2.4.4 added specifically to fix the worktree hard blocker. Ten of sixteen installed skills and three of seven shared contracts had drifted the same way, in both the Claude and the Codex global trees; a fourth shared contract differed only in line endings, which is why the comparison normalises them. So a fix could be shipped, verified and still absent from the environment that runs it, with the tool reporting health.

#### Acceptance Criteria

- [ ] AC-1: A globally installed skill whose body differs from the bundled source is reported as `warn`, naming that skill and the command that refreshes the global install.
- [ ] AC-2: A project-local agent skill directory whose body differs from the bundled source is reported as `warn`, naming that skill and the command that refreshes the project install.
- [ ] AC-3: A skill present in the bundled source and absent from a provisioned installed directory is reported as missing, distinguished in the message from one that diverged.
- [ ] AC-4: An installed directory that does not exist reports `ok` with a message saying nothing is provisioned, so an uninstalled project is not reported as drifted.
- [ ] AC-5: A shared contract file under `_shared/kiwi` that differs from the bundled copy is reported, and one that matches is not.
- [ ] AC-6: A copy that differs from the bundled source only in line endings reports `ok`.
- [ ] AC-7: The project mirror's exclusion manifest does not suppress a report for the same skill name installed globally.
- [ ] AC-8: The global comparison is driven by an injectable home directory rather than the process environment, so the check is deterministic under test and never reads the developer's own home.
