## 1. Scope Overview

이 문서는 SpecKiwi v1.0.0의 Node.js LTS 기반 TypeScript ESM 구현 구조, core module, patch engine, testing, package scripts를 정의한다.

## 2. Scope Boundaries

### In Scope

- Node.js LTS runtime
- TypeScript ESM package
- core module layout
- line-based patch engine
- MCP SDK adapter
- CLI adapter
- test fixtures and scripts

### Out of Scope

- 브라우저 런타임
- CommonJS dual package
- Rust/Python 구현
- 웹 서버 제품화
- 데이터베이스 저장소

## 3. Assumptions and Constraints

- Node.js 24 LTS를 권장한다.
- package metadata는 `package.json`에 둔다.
- MCP SDK 의존성은 adapter에 격리한다.

#### Requirement

#### Rationale

-

#### Acceptance Criteria

- [ ] AC-2: When the step SRS file already exists, a subsequent synthesis is an idempotent no-op that returns { written:false, skipped:true } and leaves the existing file byte-identical, even when a source input (e.g. intent.md) was mutated after the first run.
