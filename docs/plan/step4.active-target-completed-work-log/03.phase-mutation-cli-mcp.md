## 1. 목표

Completed Work Log를 core mutation으로 안전하게 추가하고, CLI와 MCP가 같은 core query/mutation을 호출하도록 연결한다. Active Target read path는 empty value를 정직하게 반환하고 fallback target을 만들지 않는다.

## 2. 선행 조건

- P2의 `IndexDocument.completedWork`와 `listCompletedWork()`가 구현되어 있어야 한다.
- `TargetSummary.completedWork` output shape가 확정되어 있어야 한다.
- table pipe escaping은 구현하지 않고 mutation input에서 pipe 문자를 거부한다.

#### 구현 가이드

1. `AddCompletedWorkInput`은 `date`, `summary`, optional `target`, `scope`, `requirementIds`, `dryRun`을 가진다.
2. `date`와 `summary`는 trim 후 비어 있으면 `USAGE` failure를 반환한다.
3. `date`가 `YYYY-MM-DD` 형식이 아니면 historical warning에 맡기지 않고 mutation input 단계에서 `USAGE` failure를 반환한다.
4. `date`, `target`, `scope`, each requirement ID, `summary`에 `|`가 있으면 `MUTATION_DENIED`를 반환한다.
5. `docs/spec/00.index.md`를 `readUtf8File()`로 읽는다.
6. `Completed Work Log` heading을 regex로 찾는다.
7. section이 있으면 그 아래 table을 `parseMarkdownTable()`로 찾는다.
8. table이 있으면 `table.endLine`에 row를 insert한다.
9. section은 있고 table이 없으면 heading 다음 빈 줄 뒤에 header, separator, row를 insert한다.
10. section이 없으면 `Change Notes` heading 앞에 section block을 insert한다.
11. `Change Notes` heading도 없으면 file end에 section block을 append한다.
12. row는 `| ${date} | ${target ?? ""} | ${scope ?? ""} | ${requirementIds.join(", ")} | ${summary} |` 형식으로 렌더링한다.
13. `createPatchPlan()`과 `applyPatchPlan()`을 사용하고 `summarizePatch()`를 반환한다.
14. dry-run이면 파일은 바꾸지 않고 preview를 반환한다.

#### Rationale

Completed Work Log는 index file의 table mutation이므로 Requirement Block mutation과 분리한다. core mutation으로 구현해야 CLI/MCP 동작과 dry-run behavior가 동일해진다.

#### 함정 / 주의사항

- `parseMarkdownTable()`는 escaped pipe를 처리하지 않는다. input에서 pipe를 거부해야 round-trip 손상이 없다.
- section insertion은 exact section number가 아니라 heading text를 기준으로 한다.
- Change Notes 앞 삽입은 사람이 읽는 index 흐름을 보존한다.
- newline style 보존은 existing patch engine behavior를 사용한다.

#### 테스트 작성 지침

- 성공: 기존 Completed Work Log table에 row를 추가한다.
- 성공: section은 있고 table이 없는 index에 table과 row를 만든다.
- 성공: section이 없는 legacy index에 section을 만든다.
- 실패: summary에 pipe가 있으면 파일이 바뀌지 않는다.
- 실패: `date`가 `YYYY-MM-DD` 형식이 아니면 파일이 바뀌지 않는다.
- 경계: `dryRun: true`는 patch preview만 반환한다.
- 경계: CRLF fixture에서 CRLF를 유지한다.

#### 구현 가이드

1. `read.ts`에 `completed-work` command를 추가한다.
2. options는 `--target <target>`, `--scope <scope>`, `--since <date>`, `--limit <n>`, `--json`을 지원한다.
3. limit는 positive integer로 parse하고 invalid value는 Commander error로 처리한다.
4. since는 `YYYY-MM-DD` 형식이 아니면 Commander error로 처리한다.
5. command output은 `{ completedWork: listCompletedWork(workspace, filter) }`를 기본으로 한다.
6. target filter 결과에는 targetless cross-target rows가 포함됨을 test한다.
7. `active-target` command output은 `{ activeTarget, summary }`를 유지하되 empty Active Target과 `summary.completedWork` 포함 여부를 test한다.
8. `mutations.ts`에 `add-completed-work` command를 추가한다.
9. required options는 `--date <date>`와 `--summary <summary>`다.
10. optional options는 `--target <target>`, `--scope <scope>`, `--requirements <ids>`, `--dry-run`, `--json`이다.
11. `--requirements`는 comma split, trim, empty drop으로 배열을 만든다.
12. command는 `addCompletedWork(await rootFrom(command.opts()), input)`을 호출한다.
13. mutation failure는 기존 mutation command처럼 exit code 5로 둔다.

#### Rationale

CLI는 사람이 직접 완료 로그를 조회/추가하는 표면이다. MCP와 같은 core service를 호출하면 behavior drift가 줄어든다.

#### 함정 / 주의사항

- root option은 top-level `command.opts().root`만 사용한다.
- JSON output은 valid JSON 한 줄을 유지한다.
- human output은 existing `writeHuman()` fallback JSON formatting을 사용해도 된다.
- `--requirements`가 비어 있으면 empty array로 전달한다.

#### 테스트 작성 지침

- 성공: `completed-work --json` output이 fixture row를 반환한다.
- 성공: `completed-work --target v1.0.0 --scope CLI --since 2026-05-10 --limit 1 --json` filter가 동작한다.
- 성공: `completed-work --target v1.0.0 --json`은 targetless cross-target row를 포함한다.
- 성공: 빈 Active Target fixture에서 `active-target --json`은 `activeTarget: ""`와 `summary.completedWork`를 반환한다.
- 성공: `add-completed-work`가 index에 row를 쓴다.
- 성공: `add-completed-work --dry-run --json`은 파일을 바꾸지 않고 patch preview를 반환한다.
- 실패: summary에 pipe가 있으면 exit code 5와 structured failure가 나온다.
- 실패: invalid `--since` 또는 invalid `--limit`는 command usage failure를 반환한다.
