#### 구현 가이드

1. `loadBundledRulesDocument()` resolves `docs/rule/SRS-MD-Rules-v1.0.0.md` relative to the package module path, not `process.cwd()`.
2. Keep fallback stub only for genuine missing package artifact and surface a warning or diagnostic through init output if available.
3. Add package smoke test that packs or installs from the local package artifact and runs init from an external directory.
4. Ensure root `AGENTS.md` and `CLAUDE.md` exist in this repository with current managed block.
5. Decide lowercase `agents.md` policy in docs: mirror intentionally or mark non-canonical. Do not delete user content.
6. Tests cover old managed block replacement by versioned heading and suffix marker.

#### Rationale

Installed CLI can run outside the source checkout. Cwd-relative rules loading can create stub rules and silently weaken every initialized project.

#### 함정 / 주의사항

- `import.meta.url` path resolution must work after TypeScript build in `dist/core/bootstrap/templates.js`.
- Package `files` already includes rules doc; smoke test should prove it.
- Root file creation must preserve unrelated user content.

#### 테스트 작성 지침

- 성공: external init writes full rules doc containing the diagnostic catalog, not fallback stub only.
- 성공: root uppercase agent files exist and contain current managed block.
- 성공: older versioned managed block is replaced while surrounding content remains.
