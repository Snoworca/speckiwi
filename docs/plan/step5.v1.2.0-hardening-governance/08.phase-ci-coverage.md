#### 구현 가이드

1. Add `test:coverage` script using Vitest coverage.
2. Configure global coverage threshold at 80 percent.
3. Configure parser, validator, mutation, workflow thresholds at 90 percent.
4. Add `.github/workflows/ci.yml` with Node 22, `npm ci`, and the command list from `OPS-NODE-002`.
5. Include `node bin/speckiwi validate --json` in CI.
6. Package smoke test proves installed CLI init can load full bundled rules.
7. Keep CI commands as separate YAML steps for clear failure ownership.

#### Rationale

Release governance should not rely only on local discipline. CI must prove the same gates before a v1.2.0 baseline is accepted.

#### 함정 / 주의사항

- Coverage provider dependency may need package update. Add only the dependency required by Vitest coverage.
- Performance test can be slower; keep timeout already configured in package script.
- CI should not require secrets.
