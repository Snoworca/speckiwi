#### 구현 가이드

1. Red: `extract --json`이 normalized requirement record array를 반환하고 `--include-markdown`이 raw block을 포함하는 테스트를 추가한다.
2. Red: `extract` 기본 출력이 사람이 읽는 compact list이며 JSON parse 대상이 아닌 것을 검증한다.
3. Red: `extract --target`, `extract --status`, `extract --scope`, `extract --type`, `extract --tag` 각각이 해당 조건만 만족하는 records를 반환해야 한다는 테스트를 추가한다.
4. Red: `extract --target ... --scope ... --type ... --tag ... --json` 조합 필터가 AND 조건으로 동작하는 테스트를 추가한다.
5. Red: `list --target v1.0.0 --format json`이 해당 target의 records만 반환하고 다른 target record를 제외하는 테스트를 추가한다.
6. Red: `list --status implemented --format json`이 해당 status의 records만 반환하고 다른 status record를 제외하는 테스트를 추가한다.
7. Red: `list --target v1.0.0 --status implemented --scope WEB --type FR --tag todo --format json` 조합 필터가 AND 조건으로 동작하는 테스트를 추가한다.
8. Red: `list --scope ARCH --format plain`과 `list --format table` output이 JSON이 아니며 ID를 포함해야 한다는 테스트를 추가한다.
9. `extract` command에 `--target`, `--status`, `--type`, `--scope`, `--tag` options를 추가한다.
10. `extract`에서 `listRequirements(workspace, parseFilter(options))`를 사용한다.
11. `list`도 `extract`와 같은 `parseFilter(options)` path를 사용하여 `--target`, `--status`, `--scope`, `--type`, `--tag`를 모두 적용한다.
12. `list`에서 `--format json`이면 JSON output과 동일하게 처리한다.
13. `--format plain`은 ID, status, title을 줄 단위로 출력한다.
14. `--format table`은 tab-separated rows를 출력한다.
15. 알 수 없는 format은 command error exit code 2를 반환한다.

#### Rationale

`extract`와 `list`는 같은 query filter 계약을 공유해야 한다. `list --format`은 자동화와 사람이 읽는 output을 구분하기 위한 CLI surface다.

#### 함정 / 주의사항

- `--json`과 `--format json`이 함께 있으면 JSON이 우선이다.
- `parseFilter()`가 이미 list path에서 쓰이므로 새 filter parser를 만들지 않는다.
- SRS는 `--format table|plain|json`을 요구하므로 세 값 이외의 format은 usage error다.

#### 테스트 작성 지침

- 성공: `extract` compact list, JSON records, include-markdown, target/status/scope/type/tag 단일 필터, 조합 필터를 모두 검증한다.
- 성공: `list --target`, `list --status`, `list --scope`, `list --type`, `list --tag` 단일 필터와 multiple filters AND 조합을 모두 검증한다.
- 실패: `list --format xml` exits 2 and writes stderr.
- 경계: `list --format json` and `list --json` return equivalent JSON shape.
