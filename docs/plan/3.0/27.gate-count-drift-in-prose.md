# 27. 게이트 표의 개수를 산문이 되풀이하지 않게 한다

| Field | Value |
|---|---|
| 우선순위 | MEDIUM — 정확도 |
| 근거 | 계획 [09번](09.tdd-review-hop.md) 검증 라운드 1 의 부수 관찰, 두 담당자가 각각 확인 |
| 선행 항목 | 없음 |
| 대상 | `skills/{claude,codex,etc}/kiwi-tdd/SKILL.md` 와 그 미러, 그리고 같은 형태를 가진 다른 스킬 |

## 0. 이 항목이 생긴 경위

`kiwi-tdd` §0.AG 의 `critical_gates[]` 표는 **네 행**입니다.

- `step-claim-write-skew`
- `promote-evidence-required`
- `step-completion-gate-blocked`
- `validate-spec-error`

그런데 **그 아래 문장은 네 렌더링 전부에서 "위 3개 게이트" 또는 "the three gates above" 라고 적습니다.**

`validate-spec-error` 는 [18번](18.validate-spec-error-wiring.md)이 `FR-FLOW-164` 로 넣었습니다. 표에 행을 더하면서 그 표를 가리키는 산문의 개수를 안 고쳤습니다.

## 1. 왜 이것이 문제인가

**개수를 산문이 되풀이하면 표가 자랄 때마다 낡습니다.** 그리고 이 드리프트는 조용합니다 — 표를 읽는 검사는 행을 세지만, 산문의 숫자는 아무도 안 셉니다.

이 저장소가 같은 형태를 여러 번 잡았습니다. `FR-FLOW-169` 의 기수, `FR-FLOW-171` 의 `nineteen`(실제 18)과 `all ten`(증거로는 여섯), `FR-NODE-203` 의 호출자 "둘"(실제 셋). 매번 **산문이 센 것과 실제가 어긋난 것**이었습니다.

`FR-FLOW-164` 는 이 자리를 만들면서 그것을 몰랐습니다. 표에 행을 더하는 편집이 그 표를 가리키는 문장을 붉히지 않기 때문입니다.

## 2. 확인해야 할 것

착수 시점에 먼저 재야 합니다.

- **분모.** `kiwi-tdd` 하나인지, 다른 스킬에도 같은 형태가 있는지. 일곱 스킬의 `critical_gates[]` 절을 전부 훑어야 합니다 — `criticalGatesSection` 이 이미 일곱을 찾습니다(`FR-FLOW-164` 가 헤딩 기반으로 일반화, 09번이 재확인).
- **개수를 되풀이하는 표기가 몇 가지인지.** `3개` · `three` · `셋` · `세 게이트` 처럼 갈립니다. **표기를 세지 말고 지목을 세십시오** — 이 계획에서 어휘로 분모를 거른 사례가 여섯 번 나왔습니다.
- **개수 말고 다른 것을 되풀이하는 자리가 있는지.** 게이트 이름 목록을 산문이 다시 열거하는 자리도 같은 성질입니다.
- **고칠 방향이 둘 중 어느 쪽인지.** 산문에서 개수를 빼는 것(예: "위 게이트들")과, 개수를 표에서 파생시켜 검사가 대조하게 하는 것. **전자가 싸고 후자가 강합니다.** 둘 다 할 수도 있습니다.

## 3. 목표 상태

게이트 표에 행이 늘거나 줄면 그 표를 가리키는 산문이 낡지 않습니다.

## 4. 작업 단계

1. **§2 의 넷을 재고 방향을 정한다.**
2. **요구를 등록한다.** scope 는 `FLOW`.
3. **실패 테스트를 먼저 쓴다.** 지금 낡은 자리가 red 여야 한다. **개수를 산문에서 빼기로 했다면 "표를 가리키는 문장이 개수를 담지 않는다" 를 재고, 파생시키기로 했다면 "산문의 개수가 표의 행 수와 같다" 를 잰다.**
4. red 확인 → 세 렌더링 편집 → `skills mirror --write` → green → 회귀.

## 5. 완료 조건

- 표에 행을 하나 더하면 산문이 낡는 것을 검사가 잡는다(파생 방향) 또는 산문에 개수가 들어오면 잡는다(제거 방향). **어느 쪽이든 심어서 red 를 본다.**
- 오늘 낡은 자리 전부의 처분이 정해진다.
- **검사가 못 잡는 표기가 요구에 실측과 함께 적힌다.** 어휘로 잡는 한 열거 밖은 지나가므로, 무엇을 잡고 무엇을 놓치는지가 기록되어야 한다.

## 6. 건드리지 말아야 할 것

- **게이트 표 자체를 바꾸지 않는다.** 이 항목은 산문이 표를 잘못 세는 것을 다루지 표의 내용을 다루지 않는다.
- **`GATE_IDS` 를 건드리지 않는다.** 09번이 그것을 오케스트레이터 전용 어휘로 판정했다.
