## Per-Requirement Command Shape

```sh
node bin/speckiwi update-status <REQ_ID> verified --reason "Verified after v2.3.0 closeout gates passed." --dry-run --json
node bin/speckiwi update-status <REQ_ID> verified --reason "Verified after v2.3.0 closeout gates passed." --json
```

After each batch:

```sh
node bin/speckiwi validate --fail-on-warning --json
node bin/speckiwi summary --target v2.3.0 --json
node scripts/release-check.mjs
```

If index rollups drift, use guarded sync:

```sh
node bin/speckiwi sync-index --dry-run --json
node bin/speckiwi sync-index --expected-sha256 <sha-from-dry-run> --json
```

## Exit Criteria

- `summary --target v2.3.0` reports `implementedNotVerified: []`.
- `release:check` returns `ready:true`.
