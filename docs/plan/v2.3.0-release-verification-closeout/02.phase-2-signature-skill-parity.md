# Phase 2 - Workflow Signature and Skill Snippet Parity

## Objective

Fix runtime documentation drift before `REL-FLOW-002`, `MIG-FLOW-003`, or `MIG-FLOW-004` can be verified.

## Findings

The canonical and runtime-installed `kiwi-pipeline` skill documents mention the unsupported command:

```text
speckiwi workflow next-work-order --json
```

The actual CLI command is:

```text
speckiwi workflow work-order next --json
```

The existing parity tests check for the correct appendix snippet but do not reject stale unsupported snippets in skills.

## Implementation Checklist

- [ ] Update `skills/codex/kiwi-pipeline/SKILL.md` to use `speckiwi workflow work-order next --json`.
- [ ] Reinstall the Codex skill mirror with `node bin/speckiwi --root . skills install codex kiwi-pipeline --json`.
- [ ] Add or tighten a scanner test so skill docs fail if they contain `speckiwi workflow next-work-order`.
- [ ] Confirm `.agents/skills/kiwi-pipeline/SKILL.md` matches the source mirror.

## Verification

Expected behavior:

- The old command fails with structured usage error.
