## 1. What happened, and the one sentence that matters

The predecessor's §4 said: **dispatch independent verification before starting any new item.** That
was done — seventeen agents, two lenses over ten requirements — and the result reframes the branch.

**Every one of the seven blast-radius audits returned LEAKS. Not one of the ten requirements was
cleanly promotable.** Four came back PROMOTABLE on evidence carriage and were still holed by the
second lens. The audits found, among other things, three defects that were **shipped and live**:

1. **`orchestrate_round_record` was uncallable through MCP in every case.** The binding never gained
   `--proof`; `orchestrateArgv` emits a flag only for a declared option, so commander refused every
   call with exit 2, and the input schema derives from the same binding so no caller could supply it
   deliberately. Found independently by two lenses.
2. **A round record masked an interrupted verb.** `verbKey` is `verb|wave|stage|lane`; every verb a
   round record projects is a real program-counter verb and the record carries no stage and no lane,
   so it landed in that verb's own bucket, and — written as a `result` — became the bucket's last
   line. `firstInterruptedVerb` then read an unmatched `intent` as finished, so **a resumed run would
   skip the verb it was interrupted inside**.
3. **The hedge detector silenced Korean.** The `\p{L}\p{N}` word boundary shipped the previous session
   killed all 48 token-particle forms across the six Hangul tokens, plus `maybe라는`, `roughly한`.
   Korean writes no space before a particle, so that boundary silences the ordinary written form of
   the language rather than an embedding.

The lesson to carry: **the previous session's own §7 said "nothing added this session is verified",
and that was the honest half. The dishonest half was invisible — four requirements read PROMOTABLE
until a second, differently-aimed lens looked.** One lens is not verification.

### 3.1 The two things worth stealing

**Mutation is the only test of a test.** Five mutations were run against the repaired
`FR-NODE-169`/`170` assertions; **two still survived the first repair**. `not.toBe(0)` does not catch
`requiredOption` → `option`, because the command still fails, just differently. Three arms of a
verdict map do not catch a widening to a fourth verdict that none of them produces. Both were only
found by running the mutation, not by reading the assertion.

**Line numbers in evidence rows are a recurring defect class, not an accident.** `FR-NODE-108`'s
citations were off by exactly three because three imports were added above them; `FR-NODE-166`'s
Rationale cited pre-change coordinates in the present tense and was stale against the very commit
that introduced it. Both are now cited **by symbol or by describe-block name**. Do that from the
start.

### 5.2 Close `appendWavesLine`'s payload over the declared field set · **now unblocked**

4. **`FR-NODE-164`** — AC-5's `@ts-expect-error` clause asserts over an empty set: the repository's
   only three occurrences are string literals inside the gate's own test file, which the project does

## 7. Constraints that bind the next session

The predecessor's fourteen still hold. These are added, each with an incident behind it from today.

15. **One lens is not verification.** Four requirements passed evidence-carriage and were holed by
    blast-radius. Run both, and give them different questions.
16. **Run the mutation; do not reason about it.** Two of five mutations survived the first repair of
    assertions written specifically to catch them.
17. **Never cite a line number in an evidence row.** Cite a symbol or a describe-block name. Two
    requirements carried stale citations this session, one of them stale on the day it was written.
18. **A test that reads its own source can satisfy itself.** The admission-ticket guard's first draft
    counted its own explanatory comment as a second registration. Search only the region above the
    thing you are guarding, and never spell out the construct you are counting.
19. **Do not write a branch no test can distinguish.** The hedge fix's first draft branched on script
    and both branches behaved identically under every test — the same defect class as a criterion
    whose assertion cannot fail.
20. **Editors mangle `\uXXXX` escapes and control characters.** A character class written through the
    edit path landed as literal NUL and DEL **bytes** in a source file — the exact hazard four files
    in this repo already carry. Apply anything with escapes from a script file, and grep the result.
21. **`git checkout -- <file>` after a probe discards uncommitted work in that file.** Restore from a
    copy taken before the probe, and compare sha1 both ways.
