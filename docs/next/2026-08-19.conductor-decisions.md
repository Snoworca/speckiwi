## 확정된 결정 5건

| # | 결정 | 내용 |
|---|---|---|
| 1 | **`kiwi-conductor` 승인** | A(intake)+C(harness) 합본 단일 스킬. 범위 = intake·분류·원장·라우팅·dispatch·인도·예산. 구현·검증·wave 실행은 전부 기존 스킬 위임 — 재구현 0줄 |
| 2 | **fold 규칙 유지** | lane-plan 의 단독-성분 fold 는 현행 유지, planner 쌍 강제 없음. 배치 묶음은 conductor 자체 union-find, lane-plan 은 `H-ORCH` 내부 전용 (검토 C-1 해소) |
| 3 | **인도 D-1~D-6 채택** | `--deliver` 닫힌 enum `none\|push\|pr`, base 직접 병합 없음. 기본값: `--auto` 없으면 `none`, 있으면 `pr`. push 충돌·보호 브랜치는 `--auto` 라도 중단(자식 게이트 bubble) |
| 4 | **conductor 선행, 병렬은 별도 target** | 병렬 트랙(phase2 lane 실행기 완성)은 conductor 이후, 별도 target. 한 target 에 두 트랙 금지 |
| 5 | **`H-PIPE` 는 `--wt` 없이** | host root 실행 + conductor 의 종료 후 인도 홉(`kiwi-commit-auto-pr`). run-root 불변 유지, `kiwi-pipeline` 게이트 신설 불요, 이중 PR 위험 소멸. 연구 C §1.5/D-5 의 `H-PIPE` 행은 이 결정으로 개정됨 |

결정 5는 문서에 단일 권장안이 없어 §12.2 수렴 결론("인도는 엔진 종료 후 별도 홉")에서 도출했다 — 도출 경위는 연구 문서 §12.5 항목 5 에 기록.
