## 4. Functional gaps that `release:check` cannot see

The strict check reads the SRS. It does not know whether the feature works. These are real and were
measured, and shipping "kiwi-orchestrator phase 1" with them open is a judgment call the user should
make knowingly:

1. **`route probe` echoes rather than produces.** `05` §10.6 says the verb *writes* the probe from
   declared producers; the authored `IR-CLI-082` AC-7 kept only the refuse-on-invalid clause. **That
   narrowing is recorded in no requirement**, and it is why seven routing kernels
   (`FR-NODE-111/112/115/116/117/118`) have no caller — their caller was specified away. This is the
   largest remaining item in the whole branch.
2. **`GATE_IDS` has 63 members and 34 of them appear nowhere in `src/`.**
3. **The prose gate is not wired**, and deliberately so — its admission ticket is a skipped test with
   7 findings across 4 documents in three false-positive classes.
4. **`partition-review-unrecorded` is not wired** (that is `FR-NODE-120`'s unticked criterion), and
   **`serial-unit-failed` is deliberately unwired** without the explicit declaration saying so (that
   is `FR-NODE-119`'s).

### 4.1 The one piece of engineering worth doing regardless

Close `appendWavesLine`'s payload over the declared field set. `FR-NODE-172` left **zero undeclared
fields at any typed call site**, which was the precondition. Type the payload as a record closed over
the declared union instead of `Record<string, unknown>`; an undeclared key then does not compile.

- It closes `FR-NODE-172`'s universal at compile time for all four sites at once.
- It is the check that would have caught `reason_class`.
- **Keep `journal append --payload` out of it** — it takes an arbitrary caller-supplied object by
  design and is guarded by validate-then-refuse.
- **Do not land a runtime half without candidate scoping.** `appendWavesLine` validates the whole
  resulting journal and refuses on any error, so an error-severity rule over history bricks every run
  holding one non-conforming line, including making `run abort` impossible so the lock never
  releases. That is not hypothetical: it is reproduced by a mutation probe recorded in `FR-NODE-167`
  VE-3. `checkAbortGate` is the worked precedent.
